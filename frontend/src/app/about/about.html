About

Learn more about the Foleys AI Compliance Assistant and how it supports plumbing compliance research.

Purpose

The Foleys AI Compliance Assistant is designed to help plumbing professionals find relevant compliance information more quickly.

Instead of manually searching through large standards documents, users can ask questions in natural language and receive contextual guidance based on relevant information retrieved from the compliance knowledge base.

How it works

1
Ask a question

Enter a plumbing or compliance-related question using natural language.

↓
2
Retrieve relevant information

The system searches the compliance knowledge base for information related to your question.

↓
3
Generate an answer

Relevant retrieved information is used to create a contextual AI-generated response.

↓
4
Review supporting information

Users can review the response and verify important requirements against the original compliance material.

Technology

Angular User interface
FastAPI Application API
OpenAI AI generation and embeddings
Pinecone Vector search and retrieval
⚠ Disclaimer

This assistant provides AI-generated compliance guidance. Responses may contain errors or omissions and should not replace the official standards or professional judgement. Always verify critical compliance requirements against the original source material.
